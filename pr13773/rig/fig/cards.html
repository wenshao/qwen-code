The fix holds: every target row (enabled result command Hook, restored owner) refuses on head with no child_run, task or relay row; on base the background ones wedge for the full 90 s deadline (≈300× 409) and D2/R2 show the foreground path. control rows complete on every arm, so head does not over-refuse.
Not closed by this PR (pre-existing, same on base): after a plain Harness restart (R4, R5) the previous boot's Hook lease is still held at the Broker while the restored owner reports mountHeld=false, so a catalog head does not count admits a child that then wedges — measured for a disabled command Hook (R4) and a Stop command Hook (R5); the 5-line candidate releases the stale lease on restore and fixes R4. D6/R5 on the candidate: a Stop command Hook (not counted by this PR) fires at the end of the parent turn, takes the Session mount, and the child waits it out (or, D6 on base and head 47cb7576, the child wins and the parent turn fails on its Stop Hook's 409).
